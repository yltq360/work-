# HELIO Wiki 工作区

状态：**进行中**

本目录集中保存 HELIO Wiki 页面相关的素材与辅助工具。

## 目录结构

```text
helio-wiki-resources-and-tools/
├─ homepage-screenshots/       # Bambu Studio / Orca 首页截图
├─ integration-demo-gifs/      # 集成演示 GIF
└─ windows-mov-to-gif-tool/    # Windows MOV → GIF 本地转换工具
```

## 内容说明

- `homepage-screenshots/`：Bambu Studio 和 Orca 首页截图。
- `integration-demo-gifs/`：Bambu Studio 集成及 Enhance 演示动画。
- `windows-mov-to-gif-tool/`：保持原尺寸和源时间节奏的 Windows MOV→GIF 工具，详细使用方法见其独立 README。

新增素材时，请按页面或用途继续放入对应分类，不要直接堆放在本目录根部。
