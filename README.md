## 整理规则

- 每个项目使用独立的一级目录。
- 项目素材放在 `assets/`，可复用工具放在 `tools/`。
- 大型第三方二进制文件不直接提交到 Git；在对应工具的 README 中记录获取方法。
- 临时文件、转换中间文件和本机配置不进入仓库。

后续新增工作时，请先在本页增加项目索引，再放入对应项目目录，避免所有文件堆在仓库根目录。
