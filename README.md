## 整理规则

- 文件夹名称直接说明用途，避免使用 `home`、`work` 等含义不清楚的名称。
- 页面截图、演示 GIF 和工具分别使用独立目录。
- 大型第三方二进制文件不直接提交到 Git；在对应工具的 README 中记录获取方法。
- 临时文件、转换中间文件和本机配置不进入仓库。

后续新增内容时，请先放入对应的用途目录；出现新的大类时，再在本页增加索引。
